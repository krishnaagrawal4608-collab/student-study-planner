# Student Study Planner

A simple web-based study planner designed to help students organize their daily study tasks and track their progress.

## Features

- Add study tasks
- Mark tasks as completed
- Delete tasks
- Search tasks
- Filter tasks by status
- Progress percentage
- Progress bar
- Dashboard statistics
- Dark and Light mode
- Tasks saved using LocalStorage
- Responsive design
- Smooth CSS animations

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Use

1. Enter the subject name.
2. Enter the study task.
3. Select the due date.
4. Click "Add Task".
5. Mark tasks as completed when finished.
6. Use search and filters to manage tasks.
7. Switch between Dark and Light mode.
